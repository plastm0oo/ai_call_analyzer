# AI Call Analyzer — Руководство по настройке и интеграции LLM-пайплайна

## Обзор

Этот модуль анализирует транскрипты звонков отдела продаж с помощью **GigaChat** и
мультиагентного LLM-пайплайна.

Этапы пайплайна:

1.  **Определение структуры диалога**
2.  **Проверка соответствия скрипту продаж**
3.  **Обнаружение ошибок менеджера**
4.  **Рекомендации по коучингу**
5.  **Генерация итогового отчёта**

Вход: **транскрипт звонка (текст)**\
Выход: **структурированный JSON-отчёт** для бэкенда/фронтенда.

# Описание файлов

## gigachat_client.py

Обеспечивает взаимодействие с GigaChat API: - получает OAuth-токен - отправляет
запросы к `chat/completions`

## agents.py

Ядро LLM-пайплайна: - последовательно запускает агентов - агрегирует результаты -
возвращает единый словарь с анализом

## utils.py

Вспомогательные функции (в основном чтение файлов знаний).

## export_report.py

Экспортирует результаты в:

-   `report.json`
-   `report.txt`

## test_agents.py

Пример скрипта, демонстрирующего работу пайплайна.

## Папка knowledge

Содержит доменные знания, используемые LLM:

  Файл             Назначение
  ---------------- --------------------------
  stages.txt       этапы звонка продаж
  script.txt       эталонный скрипт
  criteria.txt     ошибки менеджера
  coach_tips.txt   рекомендации по коучингу

# Настройка окружения (.env)

Создайте файл `.env` в корне проекта.

Пример:

    GIGACHAT_AUTH_KEY=YOUR_AUTH_KEY
    GIGACHAT_SCOPE=GIGACHAT_API_PERS
    GIGACHAT_MODEL=GigaChat-2-Pro
    GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
    GIGACHAT_API_URL=https://gigachat.devices.sberbank.ru/api/v1/chat/completions

------------------------------------------------------------------------

# Важно: что указывать в GIGACHAT_AUTH_KEY

Необходимо вставить **Ключ авторизации (Authorization Key)** из кабинета
разработчика GigaChat.

Это НЕ access token.

Система автоматически сгенерирует `access_token` самостоятельно.

------------------------------------------------------------------------

# Получение ключа GigaChat

1.  Откройте панель разработчика GigaChat
2.  Нажмите **Получить ключ**
3.  Скопируйте **Ключ авторизации (Authorization Key)**
4.  Вставьте его в `.env`

------------------------------------------------------------------------

# Как работает аутентификация

1.  `.env` содержит `Authorization Key`
2.  `gigachat_client.py` запрашивает OAuth-токен
3.  Получает `access_token`
4.  Использует его для вызова модели

Время жизни access-токена \~30 минут.\
Текущая реализация автоматически обновляет токен при необходимости.

# Пример utils.py

``` python
def load_text(path: str) -> str:
    with open(path, "r", encoding="utf-8") as f:
        return f.read()
```

------------------------------------------------------------------------

# Запуск пайплайна

Пример скрипта: `test_agents.py`

``` python
import json
from agents import GigaChatAgentPipeline
from utils import load_text
from export_report import export_report, export_text_report

transcript = """
Менеджер: Добрый день, меня зовут Анна.
Клиент: Да, слушаю.
Менеджер: Как вы сейчас контролируете качество звонков?
Клиент: Пока вручную.
"""

pipeline = GigaChatAgentPipeline(debug=False)

result = pipeline.run_pipeline(
    transcript=transcript,
    stages_text=load_text("knowledge/stages.txt"),
    script_text=load_text("knowledge/script.txt"),
    criteria_text=load_text("knowledge/criteria.txt"),
    coach_tips_text=load_text("knowledge/coach_tips.txt")
)

print(json.dumps(result, ensure_ascii=False, indent=2))

export_report(result)
export_text_report(result)
```

``` python
def analyze_call(transcript: str):
    return pipeline.run_pipeline(...)
```
